# Приложение "Индентер" на C++, SDL3
[![en](https://img.shields.io/badge/lang-en-green.svg)](https://github.com/kolyaka32/Indenter-app/blob/main/README.md)  [![ru](https://img.shields.io/badge/lang-ru-green.svg)](https://github.com/kolyaka32/Indenter-app/blob/main/README-ru.md)

Этот репозиторий содержит специализированное приложение "индентер" для управления соответсвующим прибором

![Изображение приложения](/screenshots/main-ru.png?raw=true)


## Использование
Это специализированное приложение для управления "индентором" - специальным инструментом для определения физических параметров исследуемого материала. Для этого программа позволяет выбрать порт, к которому подключен сам [инструмент](https://github.com/kolyaka32/Indenter-controller). После этого программа начинает получать данные и отображать их на экране в соответствии с координатами. Для управления можно перемещать измерительную головку с заданной скоростью с помощью соответсвующих кнопок слева. Для упрощения и автоматизации измерений в программе предусмотрен собственный интерпретируемый псевдоязык программирования, а Для удобства взаимодействия предусмотрена система сохранения и загрузки программ (работающая и между сеансами). В качестве результата работы можно экспортировать таблицу в формате .csv.
